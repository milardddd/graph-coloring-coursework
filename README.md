# Розфарбовування графів (Graph Coloring)

Курсова робота з дисципліни "Основи програмування". Інтерактивний веб-додаток для вирішення комбінаторних задач на графах із застосуванням об'єктно-орієнтованого підходу.

## 🚀 Функціонал

- **Два режими введення:**
  - 🖊️ Інтерактивне полотно (Canvas) для малювання вершин та ребер мишею.
  - ⊞ Матриця суміжності з автоматичною синхронізацією графічного представлення.
- **Алгоритми розв'язання:**
  - Жадібний алгоритм (Welsh-Powell).
  - Пошук з поверненням (Backtracking) з евристикою MRV (Minimum Remaining Values).
  - Пошук з поверненням зі степеневою евристикою.
- **Аналітика та експорт:**
  - Порівняльний аналіз швидкодії алгоритмів (в мілісекундах).
  - Експорт результатів (схема розфарбування, список ребер/вершин, матриця) у `.txt` файл.

## 🛠 Технологічний стек

- Frontend: React, Next.js
- Мова: TypeScript
- Стилізація: Tailwind CSS
- Візуалізація: HTML5 Canvas API

## 🏗 Архітектура (ООП)

Проєкт побудовано з використанням класичних патернів об'єктно-орієнтованого програмування:
- `GraphColoringAlgorithm` — абстрактний базовий клас для алгоритмів.
- `GraphRenderer` — клас, що інкапсулює логіку відмальовування графічного інтерфейсу на Canvas.
- `GraphAlgorithmException` — кастомний клас для обробки виключень та таймаутів.

1. Клонуйте репозиторій:
